02 · Expertise

Three disciplines, one system.

Most problems I'm handed cross all three: the data has to be modelled and moved, reasoned over by models or agents, and served securely to real users. The pixel scenes aren't decoration — each one is a small, working simulation of the idea beside it.

Data engineering

Lakehouse platforms that stay fast, governed and cheap to run.

I design metadata-driven pipelines on Microsoft Fabric, Azure Data Factory, Synapse and PySpark, organised as Bronze → Silver → Gold layers so every stage is reusable and configuration-driven rather than hand-built for each source.

  • Built a Kusto cluster-scaling framework — adaptive recursive time-window downshifting plus dynamic vertical and horizontal scaling — processing high-volume telemetry reliably at ~30% lower compute cost.
  • Modelled governed Lakehouse datasets and semantic models using star and snowflake schemas; DAX and partition-based incremental refresh cut refresh time by 55%.
  • Built operational monitoring for 300+ ADF pipelines: health, freshness, SLA compliance and failures.
  • Built batch and streaming ETL with Kafka, Spark Structured Streaming and Delta Lake.
